# CAPI, Pixel, Dataset e Atribuição

> **ATENÇÃO: este conjunto está EM DESENVOLVIMENTO e NÃO está disponível ao cliente. Não prometer, não dar prazo, não usar como argumento de venda.**

## Conceitos (apenas para contexto interno do agente)

- **Pixel**: rastreamento de eventos no site/landing.
- **Dataset**: agrupamento de eventos para a Meta.
- **CAPI (Conversions API)**: envio de conversões servidor-a-servidor para a Meta.
- **Atribuição de Meta Ads**: ligar a conversa/venda ao anúncio que originou o lead.
